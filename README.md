## Что это

Приложение проводит покупателя по чеклисту: экран, батарея, память, датчики, связь, система. Каждую проверку можно пропустить — в отчёте она так и останется «пропущено», а не «ок». В конце формируется отчёт, который сохраняется на SD-карту в `.txt` и `.json`.

> ⚠️ Результат информационный и не гарантирует отсутствие скрытых дефектов.

## Проверки

### Основные
| | Проверка | Что делает |
|---|---|---|
| 🖥 | **Экран** | Заливки чёрным, белым, красным, зелёным, синим, серым (двойной тап — дальше). Тач-тест как в сервисном меню Samsung `*#0*#`: клетки по периметру и крестом, путь пальца остаётся на экране. Тройной тап — выход. |
| 🔋 | **Батарея** | Здоровье (если система отдаёт или можно оценить), заряд, температура, напряжение, состояние, циклы (Android 14+), подключение зарядки. |
| 💾 | **Память** | Заявленный и реальный объём, свободно, ОЗУ. Запись и чтение тестового файла до 4 ГБ с проверкой контрольных сумм — ловит подделку объёма. Скорость записи/чтения. |
| 📡 | **Датчики** | Только реально имеющиеся: акселерометр, гироскоп, автоповорот, компас, барометр, приближение, освещённость, датчик Холла, шагомер, ИК-порт, вибромотор, отпечаток, кнопки громкости и питания. |
| 📶 | **Связь** | Wi-Fi (скан сетей), Bluetooth (поиск устройств), GPS (число спутников), NFC (модуль + чтение второго телефона), число SIM-слотов. |
| ℹ️ | **Система** | Модель, Android, патч безопасности, стоковая/кастомная прошивка, загрузчик, признаки root, админ-приложения. **Root и разблокированный загрузчик — не минус**, только информация. |

### Дополнительные
Открываются тапом по заголовку «Проверка» на главном экране.

| | Проверка | Что делает |
|---|---|---|
| 📷 | **Камеры** | Видео со звуком, переключение камер, зум 0.6×/1×/2×/макс + ползунок, вспышка, индикатор микрофона. Просмотр снятого на весь экран с pinch-zoom. |
| ⚡ | **Зарядка** | Ток (мА) и мощность в реальном времени, график — видно плохой разъём. |
| 🔥 | **Стресс-тест** | 2 минуты нагрузки на все ядра, график температуры батареи и CPU, предупреждение о перегреве. |
| 🛡 | **Подлинность** | Сверка заявленной модели с реальным железом: SoC, ядра, архитектура, разрешение экрана, ОЗУ, память. |

## Установка с SD-карты

1. Скачайте `PhoneChecker-*.apk` из [Releases](https://github.com/screpka228/phone-checker/releases) (или из артефактов последней сборки в [Actions](https://github.com/screpka228/phone-checker/actions)).
2. Скопируйте APK на SD-карту.
3. На проверяемом телефоне откройте файл через «Файлы» / файловый менеджер.
4. Разрешите установку из этого источника, когда Android спросит.
5. После проверки приложение можно удалить.

Требуется Android 8.0 и новее. Обновления ставятся поверх старой версии (все релизы подписаны одним ключом).

## Сборка

Нужны JDK 17 и Android SDK 35.

```bash
gradle assembleDebug
```

### Подписанный release в GitHub Actions

Workflow [`.github/workflows/build.yml`](.github/workflows/build.yml) собирает подписанный APK, если в репозитории заданы секреты. Без них собирается debug-версия. Тег `v*` (например `v1.0.0`) дополнительно публикует APK в Releases.

**1. Создайте keystore один раз** и храните его в надёжном месте — без него не получится выпустить обновление, которое встанет поверх:

```bash
keytool -genkeypair -v -keystore release.jks -alias phonechecker -keyalg RSA -keysize 4096 -validity 36500
```

**2. Закодируйте его в base64:**

```bash
base64 -w0 release.jks > release.jks.b64
```

(на macOS: `base64 -i release.jks -o release.jks.b64`, в PowerShell: `[Convert]::ToBase64String([IO.File]::ReadAllBytes("release.jks")) > release.jks.b64`)

**3. Добавьте секреты** в *Settings → Secrets and variables → Actions → New repository secret*:

| Секрет | Значение |
|---|---|
| `KEYSTORE_BASE64` | содержимое `release.jks.b64` |
| `KEYSTORE_PASSWORD` | пароль хранилища |
| `KEY_ALIAS` | `phonechecker` (alias из шага 1) |
| `KEY_PASSWORD` | пароль ключа |

Или через `gh`:

```bash
gh secret set KEYSTORE_BASE64 < release.jks.b64
```

Keystore **никогда не коммитится** — `*.jks` и `*.keystore` в `.gitignore`.
